# ShivanyaMS V3 — Step 27: Video Player, Captions, Related Videos and SEO

## Delivered

- Added a responsive public video player on video detail pages. It supports native browser playback controls, fullscreen, seeking, keyboard-accessible browser controls and playback speed selection (0.5× through 2×).
- Self-hosted media uses the optimized MP4 variant when present and otherwise uses the original source with its declared MIME type. YouTube and Vimeo use the validated privacy-enhanced embed URL generated by the backend.
- Added multilingual WebVTT caption tracks (`en`, `mr`, `hi`, and other valid language codes), default-track selection, track ordering, a 2 MB upload limit and public delivery only when the associated post is published.
- Added Admin Portal caption upload/list/delete controls on posts with attached video assets, plus Django Admin audit management.
- Added related video cards on the detail page.
- Added VideoObject JSON-LD structured data with title, description, poster, duration, content URL and embed URL. Script-sensitive `<` characters are escaped before embedding.

## API and schema

- Added `VideoCaptionTrack`, linked to `VideoDetails`, with unique language per video.
- Added migration `0039_video_caption_tracks.py`.
- Admin endpoints: `GET/POST /admin/content/{post_id}/video-captions/` and `DELETE /admin/video-captions/{caption_id}/`.
- Public WebVTT endpoint: `GET /content/video-captions/{caption_id}/` (published-post access only).
- `VideoDetailsSerializer` now includes caption track metadata and public track URLs.

## Editorial workflow

1. Create or edit a Video post and configure its Video Details provider/source.
2. Attach a video asset through the Media panel when self-hosting.
3. Upload `.vtt` files for English, Marathi, Hindi or other supported languages.
4. Select a default caption track if desired. The public player exposes the tracks through its native CC/subtitle controls.

## Notes

- Native browser controls determine the exact captions menu appearance and control layout; custom playback speed selector is provided alongside them.
- Captions require a valid WebVTT file and configured VideoDetails record. The Admin Portal caption manager is shown when a video asset is attached.
- External provider embeds rely on provider-side caption settings; uploaded WebVTT tracks apply to self-hosted HTML video.
- No tests, builds, migrations or database operations were run for this step.
